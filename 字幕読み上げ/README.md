# 字幕読み上げ（試作）

テレビや動画の字幕をカメラ（または PC の画面共有）で読み取り、出た順に音声で読み上げる Web アプリです。
文字読み取り（Tesseract.js）も音声合成（ブラウザ標準の Web Speech API）も端末の中で動くので、
API キーやサーバ側の処理は不要です。

## 使い方

```sh
python3 serve.py                      # PC: http://127.0.0.1:8001/
python3 serve.py --host 0.0.0.0 --https   # スマホ: 表示された https://<PCのIP>:8001/ を開く
```

- スマホのブラウザでカメラを使うには HTTPS が必要です。`--https` は自己署名証明書を使うため、
  初回に警告が出ます（「詳細」→「このサイトにアクセス」で進めます）。
- 「画面共有で開始」は PC のブラウザのみ。動画を再生しているタブやウィンドウを選びます。
- 開始後、映像の上をドラッグして黄色い枠を字幕の位置に合わせます（初期値は画面下部）。
- 初回は日本語の読み取りデータ（数 MB）をダウンロードします。

## しくみと遅れ

1. 枠内を一定間隔（初期値 0.4 秒）で切り出し、字幕の文字色（白・黄・濃い色）の画素だけを残して背景を消す
2. 行ごとに分け、文字の高さを約 30px にそろえて Tesseract で 1 行ずつ読む
3. 前回読み上げた字幕とほぼ同じ（読み取りの揺れ）なら読まない。違えば読み上げる
4. 画面に変化がなければ読み取りを省き、負荷と遅れを減らす

画面には「文字読み取り」の時間と「撮影→発声」の遅れ（ミリ秒）が表示されます。
テスト映像（1280×720、字幕 1〜2 行）では文字読み取りが 1 回 0.12〜0.25 秒でした。
実際の遅れは、これに読み取り間隔の待ち（最大 0.4 秒）と音声が鳴り始めるまでの時間が加わります。

| 設定 | 効果 |
|---|---|
| 次の字幕が出たら: すぐ切り替え | 読み途中の字幕を打ち切って新しい字幕を読む。遅れが溜まらない |
| 次の字幕が出たら: 読み終えてから | 取りこぼさないが、字幕の切り替わりが速いと遅れが溜まる |
| 2回続けて同じ文字なら読む | 誤読が減るが、読み取り間隔 1 回分遅れる |
| 読み上げ速度 | 速いほど次の字幕に追いつきやすい |

## 試作版の制限

- 字幕の後ろに字幕と同じ色の背景（白い字幕の後ろの白い空など）があると誤読しやすい
- カメラでテレビを撮る場合は、手ブレ・画面の反射・斜めからの撮影で精度が落ちる（スマホを固定すると安定する）
- 声の自然さは端末の標準音声に依存する（iPhone は「設定 > アクセシビリティ > 読み上げコンテンツ > 声」で高品質な声を追加できる）
